# 十三辙对照与扩展

本工具的押韵判定建立在**十三辙**上：每个汉字先取普通话韵母，再归入十三个辙口，同辙即视为可押。

## 几个容易踩的点

**「一七」包含三个来源**：i（里）、ü（雨）、舌尖元音（知、事、日）。它们听感不同但在十三辙里同辙。

**「人辰」与「言前」最容易混**：两者都以鼻音收尾，但一个是 -n（人、春），一个是 -an 系（天、年）。唱词里换辙是明显毛病，工具会直接报 `E_RHYME_MISMATCH`。

**「中东」包含 -ng 系全部**：eng、ing、ong、iong 都算。所以「中」「声」「风」可以互押。

**儿（er）归入「一七」**。这是通行处理，不是唯一处理；若你的流派另有规矩，用 `overrides` 改。

**入声不在表内**。普通话没有入声，古入声字现在读阴平/阳平的会被判成「平」。要按古韵处理就在规则里写：

```json
"overrides": { "白": "仄", "得": "仄", "十": "仄" }
```

## 韵脚建议是怎么来的

报错时给出的"同辙可选字"来自 `scripts/check_lyrics.py` 里的 `COMMON_RHYME`——每辙约 16 个常用字，**只作提示，不参与判定**。

要改这批提示字，直接编辑 `COMMON_RHYME` 字典即可，不影响校验结果。

## 怎么扩表

### 推荐做法：用 overrides

绝大多数问题都能靠规则里的 `overrides` 解决，不必动基础表：

```json
"overrides": {
  "年": "言前|2",     // 多音字指定读音
  "囡": "言前|1",     // 生僻字补录
  "得": "仄"          // 入声作仄
}
```

### 真要扩基础表

1. 编辑 `scripts/build_rhyme_table.py` 里的 `FINAL_TO_SCHEME`（韵母 → 辙的映射）
2. 重跑 `python scripts/build_rhyme_table.py`
3. 跑 `python -m unittest discover -s tests -t .` 确认没打破既有用例

**不要手改 `data/rhyme_table.json`**——它是生成物，下次重建会被覆盖。

## 方言怎么办

本工具的韵表基于**普通话**。皮影戏各流派多用方言演唱，实际押韵可能不同。三条路：

1. **逐个覆盖**：把该流派唱词里用到的韵脚字，按方言读音写进 `overrides`
2. **换一套规则**：为方言流派单独做一份规则文件，`meta.source` 写明依据
3. **关掉押韵**：`rhyme.enabled: false`，只用它查字数与结构

诚实地说：**方言韵的权威判定只能靠懂该方言的人**。工具能做的是把你的判定固化下来、批量复用，而不是替你判。
